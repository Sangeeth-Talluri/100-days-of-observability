# 100 Days of Observability

A 100-day series for **SREs, developers, and DevOps engineers** who want to venture into observability — and get good enough to do wonders with it.

Every day, one topic, in a proper learning sequence. Every topic is explained **in simple words first** (like to a smart five-year-old), then with the **real technical implementation**: how to use it, when to use it, what problem it solves, with working examples.

## How the series is organized

| Phase | Days | What you learn |
|---|---|---|
| 1. Foundations | 1–10 | What observability is, telemetry, the three pillars, OpenTelemetry, cardinality |
| 2. Metrics | 11–25 | Prometheus, PromQL, exporters, alerting, federation, sharding, managed Prometheus (Google / AWS / Azure) |
| 3. Logs | 26–38 | Structured logging, Loki, LogQL, Elasticsearch, Fluent Bit, log sinks, cost control |
| 4. Traces | 39–50 | Distributed tracing, sampling, Jaeger, Tempo, the OTel Collector, eBPF with Beyla and Odigos |
| 5. Visualization | 51–60 | Grafana dashboards, golden signals, SLOs, the single pane of glass |
| 6. Cloud & Platforms | 61–75 | AWS, GCP, Azure observability; Kubernetes; service mesh; serverless; databases |
| 7. Advanced Practice | 76–90 | Exemplars, profiling, incident response, cost optimization, AI/LLM observability, AIOps |
| 8. Capstone Builds | 91–100 | Full hands-on builds that put everything together |

## Who this is for

- **SREs** who own reliability and are tired of guessing during incidents.
- **Developers** who want their code to explain itself in production.
- **DevOps / platform engineers** who build the systems everyone else observes with.

No prior observability experience needed. We start at the definition and end at capstone builds across AWS, Google Cloud, Azure, and on-prem.

## The promise of each day

1. The idea, in simple terminology.
2. A real example you can picture.
3. The problem it solves, and when to use it.
4. A technical implementation part — commands, config, queries you can run.
5. Key terms, common mistakes, and a 5-point recap.
